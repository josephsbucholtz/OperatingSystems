Purpose of Code: Write a program that multiplies matrices R = A * W + B where A is the input, W is called the weights matrix, and B is the bias. 
Output: It prints out the resulting matrix R.
You will load 3 matrices A, W, and B from files that are passed in as command-line arguments

Run the Test Cases:
In Terminal...
1. gcc -o matrixmult matrixmult.c -Wall -Werror

2. ./matrixmult test/A1.txt test/W1.txt test/B1.txt

3. change test cases to A1, A2, ... A[n] and/or W1, W2, ... W[n] and/or B1, B2, ... B[n] to run different cases.
